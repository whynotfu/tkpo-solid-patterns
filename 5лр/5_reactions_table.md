# Таблица реакций банкомата на операции в разных состояниях

| Операция \ Состояние | Ожидание | Аутентификация пользователя | Выполнение операций | Заблокирован (денег нет) |
|---|---|---|---|---|
| **Ввести PIN** | Переход в «Аутентификация», проверка PIN | Нет связи с банком → «Ожидание». PIN верный → «Выполнение операций». PIN неверный → остается (попытка +1). 3 неверных → «Ожидание», карта изъята | Отказ: «PIN-код уже введен» | Отказ: «нет денег» |
| **Снять сумму** | Отказ: «Сначала введите PIN-код» | Отказ: «Сначала введите верный PIN-код» | Сумма не кратна 100, больше денег в банкомате или на счете, нет связи → отказ, состояние не меняется. Иначе выдача денег. Если деньги кончились → «Заблокирован» | Отказ: «нет денег» |
| **Завершить работу** | Ничего не происходит | Отмена → «Ожидание» | Конец сеанса → «Ожидание» | Отказ: «нет денег» |
| **Загрузить деньги** | Сумма добавляется, остается «Ожидание» | Отказ: банкомат занят клиентом | Отказ: банкомат занят клиентом | Сумма добавляется → «Ожидание» |
